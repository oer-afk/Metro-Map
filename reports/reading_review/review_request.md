# 駅名の表記・読みのレビュー依頼（GPT などに渡す用）

添付の `stations_readings.csv` は、中国（上海・広州・深圳）・香港の鉄道駅 1,354 駅の表記と読みの一覧です。
日本語話者が中国語圏の地下鉄の駅名を覚えるための学習用の地図で使っています。誤りや不自然な点を指摘してください。

## 列の意味

| 列 | 内容 |
|---|---|
| 路線網 | 上海・広州・深圳・香港・高鉄（広深港高速鉄道ほか） |
| 駅ID | 指摘の際の目印（変更不要） |
| 種別 | 地下鉄・輕鐵（ライトレール）・電車（トラム）・山頂纜車（ピークトラム）・高鉄 |
| 原表記 | 現地の表記（上海・広州・深圳・高鉄は簡体字、香港は繁体字） |
| 日本漢字 | 原表記を日本の新字体に直したもの（例: 陆家嘴 → 陸家嘴、綫 → 線） |
| 英語名 | 香港の駅のみ（参考） |
| 路線 | その駅を通る路線 |
| ピンイン | 普通話の読み（声調記号付き、分かち書きあり） |
| 普通話カナ | ピンインのカタカナ（上海・広州・深圳・高鉄の本土の駅のみ） |
| 粤拼 | 広東語の読み（香港の駅と香港西九龍站。声調は数字） |
| 広東語カナ | 粤拼のカタカナ（香港の駅） |
| 確認済み | 「済」は人が確認した駅（原則として正しいとみなす。明らかな誤りだけ指摘） |

## 表記の決まり（これに沿っているかを見てください）

- **ピンイン**: 本来の声調を付ける（軽声は使わない）。地名の多音字に注意（例: 闵行 Mǐnháng、莘庄 Xīnzhuāng、长风 Chángfēng）。
  香港の駅のピンインは繁体字を簡体字に直して付ける（香港の地名の「涌」は chōng）。
- **分かち書き**: 通名（路・公路・大道・大桥・街・寺・公园・博物馆・火车站・航站楼・新城・新村・大学・中心 など）は前と分ける。
  方位・数字＋路は分ける（Dōng Lù、Sān Lù）。残りの固有名は 3 字以下を続け書き、4 字以上は 2 字ずつ。
- **普通話カナ**: 音節ごとの対応表で機械的に作っている（例: 富锦路 フージン・ルー、陆家嘴 ルージャーズイ）。語の区切りは「・」、駅名の区切り点（·）は「／」。
  方位・数字＋路と「n号」はカナで続ける（ドンルー、イーハオ）。一般的な表記と違っても、**同じ音節に常に同じカナが当たっていれば一貫性は問題なし**とします。
- **広東語カナ**: 粤拼から対応表で作る。日本で定着した広東語由来の呼び名は優先（旺角＝モンコック、九龍＝カオルーン、尖沙咀＝チムサーチョイ など）。
  **英語由来の定着名（コーズウェイベイ等）は使わない**方針です。
- **日本漢字**: 日本の新字体。地名で略さない字は残す（龍・豫・淀・岩・粤）。

## 見てほしいこと

1. **ピンインの誤り**（多音字・声調・地名特有の読み）
2. **粤拼の誤り**（多音字・声調）
3. **カナの誤り**: ピンイン・粤拼の誤りに由来するもの、同じ音節なのに駅によってカナが違う不整合、明らかに不自然な音写
4. **分かち書き**の不自然な所（上の決まりに照らして）
5. **日本漢字**の変換の誤り（新字体にしすぎ・しなさすぎ）
6. 香港で、**定着した広東語由来の呼び名**があるのに使っていない駅

好みの問題（別の表記もあり得る、という程度）は「確信度: 低」として分けてください。

## 返してほしい形

指摘のある行だけを、次の列の CSV（またはそのまま貼れる表）で返してください。指摘が無い駅は書かなくて構いません。

```
駅ID,原表記,項目,現在の値,提案,理由,確信度
```

- 項目: ピンイン / 粤拼 / 普通話カナ / 広東語カナ / 分かち書き / 日本漢字 / その他
- 確信度: 高（明らかな誤り）／中（たぶん誤り）／低（好みの問題）
- 理由には、根拠（辞書の読み、公式の表記など）を短く書いてください。

量が多いので、路線網ごとに分けて見ても構いません（`stations_readings_<路線網>.csv` もあります）。
