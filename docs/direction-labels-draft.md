# 「●●方面」の表示名（2026-10-06 本人確定・実装済み）

所要時間検索の結果で、各区間に乗る電車の向きを「●●方面」と表示するための一覧。
実際の列車の行き先（区間運転・支線への振り分け）は考えず、路線の終着駅（直通運転は直通先の終着駅）を基本とする。

## 表示の決まり（案）

1. 原則は**終着駅**（公式の案内と同じで、現地で迷わない）。
2. 終着駅のすぐ手前（1〜3 駅）に、空港・高鉄駅など乗客の多くが目指す駅があり、終着駅がなじみの薄い駅のときは、**その駅を表示**する。
3. 終着駅も重要な駅で、手前や途中に空港・高鉄駅があるときは、終着駅のまま「**（○○経由）**」を添える。
4. 支線: 降りる駅がある側の終着駅。分岐駅より手前で降りるときは両方を併記（例: 虹桥火车站・航中路方面）。
5. 環状線: 「内回り／外回り」（現地の内圈・外圈、内环・外环）に、進む向きの次の乗換駅を「○○経由」で添える。
6. 直通運転（深圳 2号線 ↔ 8号線）: 直通先の終着駅。
7. 表記は「中国漢字/日本漢字」（例: 碧头/碧頭方面）。両者が同じなら 1 回だけ。
8. 輕鐵は「方面」も系統番号も出さない（系統が網の目で複雑なため。2026-10-06 の相談）。電車は東行き／西行きの終着（筲箕灣・堅尼地城）。

「公式表記」は本地宝の時刻表の列見出し（事業者の方向表記を転載したもの）。空欄は未収集（上海の一部・香港は終着駅表記が一般的）。
